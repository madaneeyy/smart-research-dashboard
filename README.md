## 📌 Overview

**Smart Research Dashboard** is a full-stack AI research assistant designed to help users discover, search, analyze, and understand AI/ML research and technical resources.

The project combines **Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), hybrid information retrieval, semantic embeddings, reranking, document processing, GitHub repository retrieval, and retrieval evaluation** into a single research workflow.

Instead of simply sending a question to an LLM, the system first retrieves relevant information and then uses the retrieved context to generate a response.

```text
User Question
      │
      ▼
Query Analysis
      │
      ▼
Relevant Information Retrieval
      │
      ▼
Candidate Ranking
      │
      ▼
Cross-Encoder Reranking
      │
      ▼
Evidence Selection
      │
      ▼
LLM Generation
      │
      ▼
Answer + Supporting Evidence
